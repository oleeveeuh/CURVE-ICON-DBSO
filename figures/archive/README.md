# Archived historical figures — UNVERIFIED AND INVALID

These figures were generated by the legacy pipeline
(`legacy/run_pipeline.py` + `legacy/visualization.py`) from saved
model predictions that were **misaligned with their subjects**
(predictions written in fold order, later paired with subjects in
original row order), compounded by full-dataset feature selection,
full-dataset imputation/scaling, and — when the aggregated HFO file
was absent — randomly generated placeholder features.

Consequences visible in these images:

- All models report negative R² here (−0.672 / −0.502 / −0.511),
  which contradicted the README's positive claims (0.713 / 0.845);
  both were artifacts of the same pipeline.
- Per-subject "predictions" may belong to a different subject.
- Labels like "Excellent/Good/Fair", "R²=0.7 (Good)", and PDP
  "confidence bands (±1 SE)" were arbitrary, not computed from any
  uncertainty method.

**Do not cite any number in these images.** They are kept only to
document the correction. See `docs/methodology.md`.
